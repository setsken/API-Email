Maildrop API

API отдаёт программам письма с адресов из папок: адрес, заметку к нему, код или ссылку подтверждения. Только чтение, менять через API ничего нельзя. Каждый ключ видит только свои папки.

Быстрый старт

  1. В панели откройте раздел API и создайте ключ, отметив нужные папки. Ключ показывается один раз, сохраните его.
  2. Добавьте адрес в одну из этих папок: в панели или через Telegram-бота. Письма на адреса вне папок ключа API не отдаёт.
  3. Запросите письма этого адреса:
curl "{{ base_url }}/api/v1/messages?address=kayla2@purelogic.help&limit=1" \
  -H "Authorization: Bearer mdk_ваш_ключ"

В ответе будет последнее письмо с кодом или ссылкой:

{
  "messages": [
    {
      "id": "6f1c2b9e4a7d4c0e8b1f3a5d7c9e2b40",
      "address": "kayla2@purelogic.help",
      "note": "Fansly #5",
      "folder": {"id": "a1b2c3d4", "name": "Fansly"},
      "code": "241553",
      "link": null,
      "from": "Fansly <noreply@fansly.com>",
      "subject": "Your login code",
      "received_at": 1793980800,
      "received_at_iso": "2026-11-06T16:00:00Z"
    }
  ],
  "server_time": 1793980805
}

Авторизация

Передавайте ключ в заголовке каждого запроса:

Authorization: Bearer mdk_ваш_ключ

Подойдёт и заголовок X-API-Key: mdk_ваш_ключ. Адрес API: {{ base_url }}/api/v1. Все ответы в JSON, время в секундах Unix (UTC).

GET /messages

Письма из папок ключа, самые новые первыми. По умолчанию только те, где нашёлся код или ссылка подтверждения: рассылки и уведомления сюда не попадают.

ПараметрОписание
addressТолько письма на этот адрес.
folderТолько письма из этой папки (её id).
sinceТолько письма, полученные в это время или позже (Unix, секунды).
limitСколько вернуть: от 1 до 100, по умолчанию 20.
all1 — вернуть и письма без кода и ссылки.

Поля письма

ПолеОписание
idИдентификатор письма.
addressАдрес, на который пришло письмо.
noteЗаметка к адресу из панели, пустая строка если её нет.
folderПапка адреса: id и name.
codeКод из письма, или null.
linkСсылка подтверждения из письма, или null. В письме может быть и код, и ссылка.
fromОтправитель.
subjectТема.
received_atКогда письмо получено, Unix.
received_at_isoТо же в формате ISO 8601.

Как дождаться кода

Коды приходят не мгновенно, поэтому опрашивайте API раз в 3–5 секунд:

  1. Перед запросом кода на сайте запомните server_time из любого ответа API. Время вашего компьютера может отличаться от времени сервера.
  2. Попросите сайт отправить код.
  3. Запрашивайте /messages?address=…&since=…&limit=1, пока не появится письмо.

Без since можно получить старый код от предыдущего письма. Письмо, полученное в ту же секунду, что и since, тоже попадёт в ответ, поэтому при опросе целой папки отбрасывайте уже обработанные письма по id.

GET /messages/{id}

Одно письмо с теми же полями и его HTML в поле body. Пригодится, если код не распознался: письмо можно разобрать самостоятельно (найти такие письма поможет /messages?all=1).

GET /addresses

Адреса из папок ключа. Параметр folder оставляет только одну папку.

{
  "addresses": [
    {"address": "kayla2@purelogic.help", "note": "Fansly #5", "folder": {"id": "a1b2c3d4", "name": "Fansly"}}
  ],
  "server_time": 1793980805
}

GET /folders

Папки ключа и число адресов в каждой.

{
  "folders": [{"id": "a1b2c3d4", "name": "Fansly", "addresses": 4}],
  "server_time": 1793980805
}

Ошибки и лимиты

При ошибке в ответе есть поля error (код) и message (описание).

СтатусerrorКогда
400bad_requestНеверное значение limit или since.
401invalid_api_keyНет ключа, ключ неверный или удалён.
404address_not_foundАдреса нет в папках ключа.
404folder_not_foundПапки нет среди папок ключа.
404message_not_foundПисьма нет в папках ключа.
429rate_limitedБольше 600 запросов в минуту на ключ. Заголовок Retry-After подскажет, сколько подождать.

Старые письма со временем удаляются: сервис хранит ограниченный объём почты и при его превышении убирает самые старые. Сохраняйте у себя то, что нужно надолго.

Примеры кода

Python

Нужна библиотека requests.

import time
import requests

API_URL = "{{ base_url }}/api/v1"
HEADERS = {"Authorization": "Bearer mdk_ваш_ключ"}


def server_time():
    response = requests.get(f"{API_URL}/folders", headers=HEADERS, timeout=15)
    response.raise_for_status()
    return response.json()["server_time"]


def wait_for_code(address, since, timeout=120):
    """Ждёт письмо на адрес. Возвращает код или ссылку, по таймауту None."""
    deadline = time.time() + timeout
    while time.time() < deadline:
        response = requests.get(
            f"{API_URL}/messages",
            headers=HEADERS,
            params={"address": address, "since": since, "limit": 1},
            timeout=15,
        )
        response.raise_for_status()
        messages = response.json()["messages"]
        if messages:
            return messages[0]["code"] or messages[0]["link"]
        time.sleep(3)
    return None


since = server_time()
# ... здесь софт просит сайт отправить код ...
print(wait_for_code("kayla2@purelogic.help", since))

JavaScript (Node.js 18+)

const API_URL = "{{ base_url }}/api/v1";
const HEADERS = { Authorization: "Bearer mdk_ваш_ключ" };

async function get(path, params = {}) {
  const url = `${API_URL}${path}?${new URLSearchParams(params)}`;
  const response = await fetch(url, { headers: HEADERS });
  if (!response.ok) throw new Error(`API: ${response.status} ${await response.text()}`);
  return response.json();
}

async function waitForCode(address, since, timeoutMs = 120000) {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    const { messages } = await get("/messages", { address, since, limit: 1 });
    if (messages.length) return messages[0].code || messages[0].link;
    await new Promise(resolve => setTimeout(resolve, 3000));
  }
  return null;
}

const { server_time: since } = await get("/folders");
// ... здесь софт просит сайт отправить код ...
console.log(await waitForCode("kayla2@purelogic.help", since));
